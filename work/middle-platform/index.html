The challenge

One product. Three systems.No single answer.

Product, dealer, price, stock and bill-of-material data had spread across regional systems, while dealer portals, stores, online shops and consumer apps all needed one consistent answer.

Mismatched identifiers

One product, a different ID in every regional system.

An ERP move in flight

Regions moved from legacy ERP to SAP; channels couldn't stop.

Data that must stay apart

Shared services, but each market's data stays apart.

The solution

A middle platform,built to be shared

A modular service layer between every channel and the ERP — one set of APIs, whether it runs on legacy ERP or SAP.

Design principle

Migrate underneath.Keep every channel open.

Front-end channels talk to one set of standardized APIs. Whether a region still runs its legacy ERP or has already moved to SAP, the dealer portal, the store, the online shop and the app work the same way, and each region migrates on its own timeline.
